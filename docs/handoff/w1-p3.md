## 3. 冲突登记与裁决建议（核心交付物之一）

以下差异均**未改写原文档**，请对应槽位裁决后回写自己的文件。C1/C2/C10 与 P2 已登记的 G1/G2/G3 同源，形成两槽独立交叉验证，建议优先处理。

| # | 冲突 | 涉及文档 | 裁决建议 | 建议裁决人 |
|---|---|---|---|---|
| C1 | 登录 provider 枚举（PHONE/WECHAT/DEVICE）无 TikTok 位，而 Minis 必接静默登录 | 12-api-contracts §4.1 vs 11 §4.1 | 契约新增 `{ "provider": "TIKTOK", "authCode": "..." }`；Minis 首发**仅启用 TIKTOK**，PHONE/WECHAT/DEVICE 标注「非 Minis 端预留」；`/auth/sms-codes` 同标注（=P2 G1） | W1B |
| C2 | `paymentChannel` 枚举（WECHAT/ALIPAY/APPLE_IAP）缺 `TIKTOK_BEANS`，而 Beans 是 Minis 唯一合法渠道 | 12-domain-model §5.3、12-api-contracts §4.6 vs 11 §4.2 | 新增 `TIKTOK_BEANS` 并首发唯一启用；`channelOrderId`=`trade_order_id`；`paymentPayload` 约定携带 `tradeOrderId`；`RechargeOrder` 建议增 `beansAmount` 字段（=P2 G2） | W1B |

| C4 | 兼容矩阵含微信内置 WebView/微信小程序，目标宿主实为 TikTok App WebView | 14-test-plan §6.2 | 矩阵改为：TikTok App（iOS WKWebView / Android Chromium WebView）× 最低支持 SDK 版本（Portal C7 配置项）× 低端机；微信项删除 | W1D |
| C5 | 包体积/崩溃率门禁按原生 APK/iOS 包定义，Minis 无原生包 | 14-quality-gates §5.4、G3.8 | 替代口径已给出（03-nonfunctional §2）：ZIP ≤20MB、首屏 JS ≤300KB gzip、JS 错误率 <0.5%/白屏率 <0.1%；G2.6 改核 ZIP 与首屏预算 | W1D |

| C7 | CSP `default-src 'self'` 与官方要求加载 `connect.tiktok-minis.com/drama/sdk.js` + 内联 `TTMinis.init` 冲突 | 14-security §2.1 vs 11 §2 | `script-src 'self' https://connect.tiktok-minis.com` + init 内联用 nonce/hash；`connect-src` 收敛 API/CDN 两域。此例外同时满足官方 E8「限制动态脚本来源」 | W1D |
