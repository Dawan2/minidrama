## 2. What changed

`pnpm run check:smoke` preflights `app/dist/index.html`, the named P0 specs
(`login-home`, `browse-play`), and the Playwright binary, then starts a sqlite API
(`NODE_ENV=test`, `MINIDRAMA_TEST_LOGIN=yes-i-am-a-non-production-test-deployment`) plus
a same-origin gateway that serves `app/dist` and proxies `/v1` and `/health`. The CI
client build leaves `VITE_API_BASE_URL` unset, so the bundle fetches relative URLs;
splitting static files and the API across origins would need a baked URL or a CORS guess.

The API still sees Chromium's `Origin` on same-origin POSTs. An empty CORS allowlist 403s
login while GETs without `Origin` still load the feed — that is why silent login stayed
`ANONYMOUS` until `CORS_ALLOWED_ORIGINS` named the gateway. A foreign Origin is still 403.
Playwright is spawned asynchronously so the same-process gateway can accept HTTP.
`connect.tiktok-minis.com` is aborted: that is the same discriminator `createBridge`
already uses (`window.TTMinis` absent → MockBridge). Waiting for `load` hung when egress
blocked the SDK script.

MockBridge hands `mock:usr_browser_local`. Production still refuses that code
(`createTiktokIdentityPort`). Test-login is the only path that accepts it.

The L2 job builds the client, installs Chromium, and runs `pnpm run check:smoke`. Browsers
are not downloaded on `pnpm install` (`onlyBuiltDependencies` is still only `esbuild`).
