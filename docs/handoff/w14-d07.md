over real HTTP, writes a favourite, replaces the process, and reads the favourite back. The L2
workflow gains an `integration` job on the same events it already uses (`main`, `cursor/**`,
`pull_request`, `workflow_dispatch`). Postgres is not rewritten to a file. Redis is not started.
