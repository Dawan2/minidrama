## 2. 关键结论（供其他工作槽直接引用）

1. **官方路径确认**：短剧接入走 TikTok Minis（H5 runtime）路径，官方有专属 Mini Drama 文档链（S1 Integration Workflow 为总纲，2026-08-04 更新）。另有 Drama Center 直传剧集路径，不在本项目 W1 范围。
2. **7 项必接能力**（缺一不过审）：静默登录、激励视频广告、插屏广告、Beans 支付、订阅、导航栏（2 个 API）；显式授权为可选。发布代码扫描会核查登录实现。
3. **合规链条长且串行**：企业认证 → 行业资质审核（需**其他平台代表作短剧链接** + 公司介绍；1–3 工作日）→ 变现开通签约 → US 上线还需 TPRM 审查（第三方口径 15–30 工作日）。这是整个项目的最长链路，商务侧应最先启动。
4. **硬性技术红线**：ZIP ≤200MB、无空文件、动态脚本与运行时请求域名受限、可信域名 ≤20 个（https/wss、无通配符/路径）、应用必须兼容英文、首发必须全量发布、同时最多 1 生产 + 1 灰度版本。
5. **素材规格**（短剧新文档 S4 口径）：图标 600×600（PNG/JPEG/JPG/BMP，≤6MB，无圆角/水印/二维码）、应用名 ≤50 字符、描述 ≤500 字符、需 ToS/隐私政策 URL、Apple Team ID 必填、联系邮箱需 2FA。
