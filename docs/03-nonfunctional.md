# 03. 非功能需求（Non-Functional Requirements）

> Wave 1 · 计划槽 P3。本文将 14 系列文档的门禁/安全要求折算为 **TikTok Minis（H5 in WebView）形态**下可执行的非功能预算与容量假设。
> 原则：凡 14 文档已有的阈值一律沿用不放宽（铁律 R4）；仅对「原生 App 专属、Minis 形态不适用」的条目给出替代口径，并在 `docs/handoff/w1-p3.md` §3 登记（C5/C6），由 W1D 裁决回写。

## 1. 适用形态说明

客户端为 TikTok App 内 WebView 运行的 H5 包（TikTok 托管分发），因此：

- 「安装包体积」「冷启动」等原生指标折算为 **ZIP 包体积 / 首屏资源 / WebView TTI**；
- 崩溃率指标折算为 **JS 未捕获错误率 + 白屏率**（Sentry 采集）；
- 官方硬限位于上层：ZIP ≤200MB、无空文件、域名受限（11-checklist §6.2），我方预算必须显著严于官方硬限。

## 2. 性能预算（客户端）

> 与 `docs/01-product-scope.md` §5 的产品预算（首页可交互 ≤3s@4G、起播 ≤2s@正常网络）取严：下表沿用 14-gates 的更严阈值，满足下表即满足 P1 预算。

| 指标 | 预算 | 与 14 文档关系 |
|---|---|---|
| ZIP 包体积 | ≤ 20 MB（官方硬限 200MB 的 10%；含全部静态资源） | 替代 14-gates §5.4 APK/iOS 体积项（C5） |
| 首屏 JS（gzip） | ≤ 300 KB；单 PR 增幅 >30KB 需说明 | 同上，等价「单 PR 增幅说明」机制 |
| 首屏总传输（不含视频） | ≤ 800 KB | 新增（WebView 无预装资源） |
| 冷启动到可交互（TTI，中端 Android + TikTok WebView） | P90 ≤ 2.5 s | 沿用 14-gates §5.4 冷启动预算 |
| 点击剧集到首帧起播 | P90 ≤ 1.2 s（WiFi）/ ≤ 2.5 s（4G） | 沿用 |
| 播放百秒卡顿时长 | P95 ≤ 1 s | 沿用 |
| 滑动切集（沉浸流）响应 | 切换到首帧 P90 ≤ 800 ms（预取命中时） | 新增（E-11 支撑） |
| JS 错误率 / 白屏率 | 错误率 < 0.5%会话；白屏率 < 0.1% | 替代 G3.8 崩溃率（同 0.3% 精神，白屏更严） |

**基线机型**（14-gates §5.4 / W1D §3 待定项，本槽建议，供产品槽确认）：Android 中端 = 4GB RAM、2020 年后 Chromium WebView（如 Redmi Note 系列）；iOS 低端 = iPhone SE2。首发区域（东南亚）低端机占比高，预算按该基线测量。

## 3. 服务端 SLO 与性能

| 指标 | 目标 | 来源 |
|---|---|---|
| 可用性（月度，核心链路：登录/feed/取址/下单/回调） | ≥ 99.9% | 14-test §6.1 |
| 核心 API（登录、鉴权、解锁、下单）P95 | ≤ 300 ms（服务端） | 14-gates §5.4 |
| 播放令牌签发 P95 | ≤ 200 ms（在首帧 1.2s 预算的关键路径上，需更严） | 本文新增 |
| 读接口（feed/剧集列表）P95 | ≤ 400 ms（可缓存） | 本文新增 |
| webhook 处理（验签→发货完成） | P95 ≤ 2 s；失败重试幂等 | 支撑 E-20/E-22 |
| 错误预算 | 月 0.1%；耗尽即冻结非修复类发布（对齐金丝雀自动回滚，14-gates §5.3） | 本文新增 |

## 4. 容量假设与伸缩（首发 6 个月规划口径）

| 假设 | 数值 | 推导的容量要求 |
|---|---|---|
| DAU | 50 万 | — |
| 峰值并发播放 | 5 万 | CDN 出口 ≈ 5万 × 1.5Mbps(720p) ≈ 75 Gbps（CDN 承担，origin 回源 <1%） |
| API 峰值 QPS | ≈ 3,000（含读） | 无状态副本水平扩展；单副本压测基线 ≥800 QPS |
| 进度心跳写入峰值 | ≈ 5,000 次/s（5万并发 ÷ 10s 心跳） | 走 Redis 缓冲 + 批量刷库（12 §7.2 允许最终一致），PG 不承接裸写 |
| 埋点事件峰值 | ≈ 8,000 events/s（批量上报折算） | PG 分区表起步；>5,000/s 持续时迁 ClickHouse（D7 预案） |
| 热剧上线突发 | 平峰 5 倍、10 分钟内 | 副本自动扩缩（HPA on QPS/CPU）+ feed/详情 Redis 缓存（TTL 60s） |

伸缩边界：PG 单主 + 读副本可支撑上述规模的 5–10 倍；超出后按模块拆读写（钱包/解锁保持单库强一致域）——架构上已用「模块间禁止跨库直查」保住拆分选项（03-tech-architecture §4.1）。

## 5. 可信域名预算（官方 ≤20 个硬限，11-checklist C13）

| # | 域名 | 用途 | 备注 |
|---|---|---|---|
| 1 | `https://api.<prod-domain>` | 全部 API + Sentry tunnel + AES 密钥接口 | 收敛为单域是名额策略核心 |
| 2 | `https://media.<prod-domain>` | HLS + 封面图 CDN | |
| 3 | `wss://api.<prod-domain>`（预留） | 未来实时能力（弹幕等） | 暂不启用 |

- 官方 SDK 域 `connect.tiktok-minis.com` 为平台自身域，按官方文档无需占用我方名额（以 Portal 实测为准，Q4 关联）。
- staging 域名放**沙箱应用**（D14 核对项）的独立配置，不占生产名额。
- 剩余 ≥17 个名额留给：合规页面域（ToS/隐私政策，若与 API 域分离）、第三方审核服务商（评论机审若走前端直传则需登记；默认走后端代理，不占名额）。
- **纪律**：新增可信域名需架构 owner 评审（每个域名都是攻击面与名额消耗）。

## 6. 可靠性与数据

| 项 | 要求 |
|---|---|
| 备份 | PG PITR，RPO ≤ 5 min；每日快照异区域留存 30 天 |
| 恢复 | RTO ≤ 30 min（与 14-gates §5.2 回滚时间目标一致）；每季度恢复演练（并入 14-security §9 演练日历） |
| 资金一致性 | 钱包不变式每日对账（12 §5.2）+ TikTok 订单每日全量核对 + 未回调订单主动查单（14-security §4.1）；差异生成工单，禁止静默抹平 |
| 幂等 | 资金/解锁写操作 `Idempotency-Key` + 唯一索引双保险（12 §2.4） |
| 降级预案 | ① 支付异常熔断：关闭下单保播放（14-security §9 演练项）；② 推荐降级为静态热门榜；③ 评论整体关闭开关 `features.comments`（12 §9）；④ CDN 故障：备用 CDN 域名预案（Wave 2 评估双 CDN） |
| 一键下架 | 内容下架 + CDN 失效 + 令牌拒发 ≤ 5 min 全端生效（14-security §7.3） |

## 7. 安全与合规基线（区域化）

安全技术要求全量继承 14-security（本文不复述）。区域合规矩阵（Minis 发行区不含中国大陆，基线差异登记 C3）：

| 区域 | 额外合规要求 | 技术落点 |
|---|---|---|
| 全区域 | 应用兼容英文（E14）；ToS/隐私政策 URL（C4/C5）；版权自查表（C9） | i18n 英文必备；合规页面域 |
| 欧盟式基线（默认从严） | 数据最小化、同意管理、删除权/导出权 | 沿用 14-security §6.2 用户权利清单（注销/导出/撤回同意） |
| 美国 | US Launch Approval + USDS TPRM（11-checklist §3.3） | 数据驻留与供应商清单专项评估（阻塞登记，不影响首发其余区域） |
| 越南 | G1 网络游戏牌照（11-checklist §4.3） | 商务项，技术无落点 |
| 沙特 | 内容尺度与 RTL | 内容审核策略区域化配置；前端 RTL 预留 |
| 未成年人保护 | 平台政策为准（PIPL 青少年模式细则不适用，理念保留） | 消费限额与时长提醒能力位保留（C3 裁决后定开关） |

数据驻留：origin 单区域（新加坡）起步，用户数据不出该区域云商边界；US 上线时按 TPRM 结论专项调整。

## 8. 可维护性与工程质量

- TypeScript strict 全栈，公共 API 与数据模型禁 `any`（14-test §1.4）；覆盖率阈值全量沿用 14-gates §3.1（增量 80% / 全局 60% 起步 ratchet / 核心模块 90%）。
- 核心模块清单（覆盖率 90% + 变异测试）：支付/订单、认证/会话、解锁/权益、内容审核 + 本槽建议增补的播放令牌签发（见 03-stack-decision D16）。
- 契约唯一事实源 `contracts/` OpenAPI 3.1；破坏性变更走「先加后删 + ≥2 发布周期弃用窗口」（14-test §4.1）。
- 文档即代码：本 docs 目录与代码同仓评审；架构决策变更须更新 03 系列并在 PR 说明。

## 9. 成本护栏（月度，首发规模量级）

| 项 | 量级预估 | 护栏 |
|---|---|---|
| CDN 流量 | 主要成本项（视频出口） | 按档位限速 + ABR 起播档控制；月度流量告警阈值；免费集也走 HLS 但限 720p 起播 |
| 计算（API + 任务） | 小（无状态容器 ×3–6 副本） | HPA 上限封顶 |
| 转码 | 一次性（每集 ≈3 档 × 时长） | 入库排队，非高峰执行 |
| 可观测性 SaaS | 采样控制：trace 10% 采样、日志 7 天热存 | 超量降采样而非关采集 |

预算超支 20% 触发架构复审（优先动 ABR 档位与缓存策略，禁止动安全与门禁项）。
